# Фронтенд simple-cal-com

Vite + React + TypeScript + Tailwind + shadcn/ui. Данные получает только через API по контракту
`openapi/openapi.yaml`.

## Запуск

```bash
npm install
npm run mock   # Prism по контракту на :4010
npm run dev    # интерфейс на :5173
```

Клиент всегда ходит в относительный `/api`, а Vite проксирует его на `VITE_API_PROXY_TARGET`.
Чтобы переключиться с мока на реальный бэкенд, правится только `.env.local`:

```
VITE_API_PROXY_TARGET=http://localhost:3000
```

## Команды

| Команда             | Что делает                          |

## Соглашения

- Время отображается **строго в UTC**. Вся работа с датами живёт в `src/lib/utc.ts`;
  `toLocaleString`, `getHours` и подобное вне этого модуля использовать нельзя.
- Типы API в `src/api/types.ts` описаны вручную и повторяют `openapi/openapi.yaml`.
  Меняются только следом за спекой: сначала `specs/*.tsp`, потом код.
- `src/components/ui/**` приходит из реестра shadcn и перезаписывается при переустановке
  компонентов — руками не править.

## Особенности Prism

Мок не хранит состояние: созданная бронь не появится в `GET /admin/bookings`. Слоты приходят
из примеров спеки, поэтому диапазон дней короче реального окна в 14 дней. Ошибки валидации
самого Prism приходят в формате RFC 7807, а не в `ApiError` — клиент это учитывает.
Конкретную ветку ответа можно запросить заголовком `Prefer: code=409`.
